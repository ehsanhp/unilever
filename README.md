# دیلم یونیلیور — سایت فروشگاه

سایت معرفی محصولات فروشگاه دیلم یونیلیور (بندر دیلم)  
طراحی لوکس و مینیمال سفید + پشتیبانی PWA + استعلام قیمت از طریق واتساپ

## ویژگی‌ها

- نمایش محصولات با عکس، عنوان و توضیحات
- جستجو و فیلتر بر اساس دسته‌بندی
- استعلام قیمت: مشتری نام می‌نویسد → پیام آماده در واتساپ باز می‌شود
- پنل مدیریت ساده (رمز: `admin123`)
  - افزودن / ویرایش / حذف محصول
  - ایجاد و مدیریت دسته‌بندی
  - ویرایش اطلاعات فروشگاه (آدرس، درباره ما، واتساپ و ...)
- قابلیت نصب به عنوان اپلیکیشن (PWA)
- کاملاً فارسی و راست‌چین

## دسته‌بندی‌های اولیه

عطر، اسپری، خمیر دندان، مسواک برقی و مسواک، مام، ژل شستشو صورت، شامپو، صابون، آبرسان

## نحوه استقرار روی GitHub Pages

1. یک ریپازیتوری جدید در GitHub بسازید (مثلاً `dilem-unilever`)
2. تمام فایل‌های این پوشه را داخل ریپازیتوری آپلود کنید (می‌توانید از طریق وب‌سایت GitHub یا Git)
3. بروید به **Settings → Pages**
4. Source را روی `Deploy from a branch` بگذارید
5. Branch را `main` (یا `master`) و پوشه را `/ (root)` انتخاب کنید
6. چند دقیقه صبر کنید تا سایت بالا بیاید  
   آدرس معمولاً به این شکل است:  
   `https://USERNAME.github.io/dilem-unilever/`

## پنل مدیریت

آدرس: `https://USERNAME.github.io/dilem-unilever/admin.html`  
رمز عبور: `admin123`

**نکته مهم:**  
چون سایت روی GitHub Pages استاتیک است، تغییرات پنل مدیریت فقط روی مرورگر همان دستگاه ذخیره می‌شود (localStorage).  
برای دائمی کردن تغییرات:

1. وارد پنل شوید
2. به تب «خروجی داده» بروید و فایل JSON را دانلود کنید
3. محتویات را در فایل `js/data.js` جایگزین کنید و دوباره به GitHub پوش کنید

یا می‌توانید عکس‌های تکی محصولات را داخل پوشه `images` بگذارید و آدرس آن‌ها را در پنل وارد کنید.

## ساختار پوشه

```
dilem-unilever/
├── index.html          # صفحه اصلی
├── products.html       # لیست محصولات
├── about.html          # درباره ما
├── contact.html        # تماس و استعلام
├── admin.html          # پنل مدیریت
├── manifest.json       # تنظیمات PWA
├── sw.js               # Service Worker
├── css/style.css
├── js/
│   ├── data.js         # داده‌های اولیه محصولات
│   └── app.js
└── images/             # عکس‌های قفسه و آیکون‌ها
```

## سفارشی‌سازی

- تغییر رنگ اصلی: در `css/style.css` متغیر `--accent` را عوض کنید
- افزودن عکس تکی: فایل را در `images/` بگذارید و در پنل مدیریت آدرس آن را وارد کنید
- تغییر رمز پنل: در فایل `admin.html` مقدار `ADMIN_PASSWORD` را ویرایش کنید
